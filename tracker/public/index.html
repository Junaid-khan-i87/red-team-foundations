Red Team Quick Snippet & Command Library

Networking & DNS
dig domain.com +noall +answer

Resolve DNS A record concisely.

dig axfr @ns1.domain.com domain.com

Attempt unrestricted DNS Zone Transfer.

sudo tcpdump -i any -nn -c 10 port 53

Live capture 10 DNS packets on any interface.

nc -zv 192.168.1.1 22 80 443

Fast banner check across ports.

Linux PrivEsc & Recon
find / -perm -4000 -type f 2>/dev/null

Find all SUID binaries on system.

grep -rni "password" /var/www/ 2>/dev/null

Recursive search for exposed secrets in webroot.

ss -tulpn

List listening ports and binding processes.

sudo -l

Check allowed sudo commands for current user.

Windows & PowerShell
Get-Process | Sort-Object CPU -Descending | Select-Object -First 5

Top CPU consuming processes.

Test-NetConnection -ComputerName 10.0.0.1 -Port 445

Test remote SMB port connectivity.

whoami /priv

List user token privileges (SeImpersonate, etc.).
